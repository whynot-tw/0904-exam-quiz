# 題庫次分類分析草案

## 結論

**可以新增次分類，而且建議先採「一題一個主要次分類」的模式。** 這會讓刷題、進度與弱項統計保持清楚；如果日後需要跨主題搜尋，再額外加入多標籤，而不要以重疊分類取代主要分類。

本次分析僅讀取官方 PDF 解析後的 657 題題幹與選項，沒有修改 CMS 題目、官方答案、既有課程類型或 `needs_review` 狀態。現有頂層分類仍是「電腦硬體裝修」446 題與「AI人工智慧工具應用」211 題。

## 為何不可直接自動寫入

關鍵詞掃描發現 **63 題**同時命中多個候選主題，例如 HARDWARE-142 同時涉及 Windows 與儲存／檔案系統，HARDWARE-144 同時涉及 Linux 與網路。另有 **301 題**尚未命中目前的候選關鍵詞。這些題目不應被硬塞進分類，也不應影響官方答案。

因此建議採兩段式流程：先以明確命中的題目建立候選清單；再由我依題幹主旨逐題產生「主要次分類＋信心標記」，把跨主題及未命中題目列為待確認。整批匯入前會先提供題數、範例題號與變更預覽。
