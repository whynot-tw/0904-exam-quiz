# 次分類篩選 UI QA

| 驗收項目 | 結果 |
|---|---|
| 全部課程次分類選單 | 顯示 AI 工具與生成式 AI、Windows、Linux、網路、儲存、硬體組裝與待確認。 |
| 選擇電腦硬體裝修 | 題目池顯示 439 題，AI 次分類會自選單移除。 |
| 選擇 Linux／Unix 作業系統 | 題目池縮小為 28 題。 |
| 開始回合 | Linux 篩選可進入 5 題作答，首題為 Linux 分割區題。 |
| 手機版 | 課程、次分類、題數與開始按鈕均可完整顯示與操作。 |
| Admin 後台 | 待審清單載入後顯示每題次分類與待確認標籤，並提供獨立的分類編輯入口。 |
| 次分類弱項統計 | 以登入使用者「有何不可設計所」的實際作答資料核對，桌面與手機皆顯示「本範圍優先加強：網路與通訊（答對率 0%）」；現有 AI 15 次作答／20%、硬體 15 次作答／40%。 |
| Admin 資料載入 | 同一登入 admin 帳號的待審清單載入 8 題，所有列均顯示 CMS 次分類標籤。 |

次分類只限制抽題範圍；官方題幹、選項、答案、解析、啟用狀態與 `needs_review` 狀態均未因本功能變更。
