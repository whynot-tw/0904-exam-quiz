# 錯題本流程檢查紀錄

## 結論

錯題本的產品功能已存在，且本輪檢查未發現需要新增畫面或欄位的缺口。使用者完成登入後，作答流程會將知識型答錯題目寫入個人 `wrongQuestions` 清單；「題目看反」會保留為閱讀失誤備註，不計入知識型錯題。

| 使用流程 | 既有行為 |
| --- | --- |
| 答錯記錄 | 以使用者與題號為唯一範圍，新增或累計錯誤次數並設為「待複習」 |
| 個人回顧 | 錯題分頁只讀取登入使用者自己的紀錄，依最新更新時間排序 |
| 狀態篩選 | 可選擇「待複習」、「已熟悉」或「全部」 |
| 重新作答 | 每筆錯題可定位完整官方題目並直接開啟單題重刷 |
| 熟悉判定 | 同一錯題連續答對兩次後標為「已熟悉」；再次答錯會重設為「待複習」 |
| 未登入 | 讀取個人錯題清單受登入程序保護，不會跨使用者顯示資料 |

本輪新增回歸測試，涵蓋錯題寫入、個人清單讀回、連續答對狀態更新、篩選與重刷題目定位；未修改官方題庫內容。
